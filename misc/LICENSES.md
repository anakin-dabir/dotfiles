## Fonts (`misc/fonts/`)

Each font is under its upstream license (SIL Open Font License, MIT or Apache-2.0).
See the font's own project for the full text; `MapleMono-NF/LICENSE.txt` is included.

Not included: **Cartograph CF** is a commercial font. The eww profile card and music
player widgets ask for it and fall back to another font if it isn't installed. If you own
a license, put it in `~/.local/share/fonts/` yourself.
